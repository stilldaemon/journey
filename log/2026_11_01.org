* using basic git command

** details
configuring git while using org-roam with emacs but separate them in different folder with symlink works beautifully!

** today's practice
- ~ln -s SOURCE_FILE TARGET_FILE~ make a symlink: now I know how to make a neat filetree
- ~git init~ on the folder I want
- ~git add .~  add files
- ~git diff~ to see the changes
- ~git status~
- ~git commit -m "MESSAGE"~
- ~git push~ on a existing remote repo or ~git push -u origin main~ on a new local repo
- I can just type ~cd ..~ to back one directory before. I always use ~cd $HOME~ this whole time, lol
#NOTE: only ~mv~ desired content into git folder then make a symlink, not the other way around

instead of remembering all the command line, hands-on practice with real-world projects is the best
